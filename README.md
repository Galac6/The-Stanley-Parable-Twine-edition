The Stanley Parable: Twine edition, V1.0 (Interactive Fan Adaptation)

This is mainly a personal project, aiming to learn the basics of Twine and Harlowe.

An unofficial, interactive text-adventure adaptation inspired by The Stanley Parable Demonstration, TSP HD remix and TSP Ultra-deluxe, built in Twine. (Harlowe, HTML, CSS and JS) 

Parts of this project were vibe-coded using models such as Gemini Flash, Gemini Pro, Gemini Hydrogen and Claude Sonnet 5.5. 

You can play the game directly in your browser via GitHub Pages (no download required):

Play The Stanley Parable: Twine edition : [https://Galac6.github.io/The-Stanley-Parable-Twine-edition/](https://galac6.github.io/The-Stanley-Parable-Twine-edition/)

Note: Make sure your browser's sound is enabled and the page has sound and video authorizations. If audio does not start automatically on the title screen due to browser autoplay policies, click anywhere on the page or advance to the first choice to unlock playback. Futhermore, to prevent visual glitches, you should dezoom to at least 80% of the original page.

---

All audio, video, and image assets are streamed externally via the Internet Archive so the game loads directly in the browser without large repository downloads.

---

1. Clone or download this repo.
